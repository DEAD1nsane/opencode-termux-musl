The `APK-TOOLS.checksum.SHA1` warnings are harmless — Alpine's apk
format embeds pax headers GNU tar doesn't recognize. To suppress,
add `--warning=no-unknown-keyword` to the `tar -xzf` invocations in
install.sh.
